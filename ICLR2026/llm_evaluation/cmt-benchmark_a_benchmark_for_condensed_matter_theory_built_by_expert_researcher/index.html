    CMT-Benchmark: A Benchmark for Condensed Matter Theory Built by Expert Researchers¶

    会议: ICLR 2026
    OpenReview: https://openreview.net/forum?id=pX6B28ynNh
    代码/数据: Hugging Face 数据集已公开，机器评分代码承诺后续释放
    领域: LLM 评测 / 科学推理基准
    关键词: 科学基准, 凝聚态物理, LLM 推理, 自动评分, 非对易算符, AI 研究助手

    一句话总结¶

    由全球凝聚态理论专家亲手出题，构建了 50 道研究级物理难题的 CMT-Benchmark，并用能处理非对易算符代数的自动评分管线检验 17 个前沿大模型——结果最强的 GPT-5 也只做对 30%，平均仅 11.4%，戳穿了"LLM 能当科研助手"的幻觉。

    研究背景与动机¶

    领域现状：大模型在编程和数学奥赛上已能拿金牌，数学界也已经由顶尖数学家联手造出 FrontierMath 这类专家级基准。但在硬科学领域，主流评测如 GPQA 已接近饱和、HLE 虽难却覆盖泛而不深，CMPhysBench 等物理基准也仅停留在"教科书计算题"难度。

    现有痛点：现有硬科学基准衡量的是学生做习题的知识与技巧，而非模型能否充当前沿科研助手。在凝聚态理论（CMT）这类高度专业的领域，常规众包出题根本行不通——所需专长只集中在极小的专家社区里，因此一直缺一个对标 FrontierMath 的"硬科学版本"。

    核心矛盾：科研要求的是绝对正确且可复现的判断力，要能从基本原理（对称性、标度维度）出发对计算做"sanity check"，并在语言描述与精确数学/几何之间无缝切换；而这恰恰是只会做算法化操作的 LLM 的盲区。同时，量子多体物理大量使用非对易算符代数，标准的数值/符号评分器无法判定算符表达式是否等价。

    本文目标：填补这一空白，造一个真正测"科研就绪度"的凝聚态理论基准，并配套一套能确定性、可自动判分（含算符代数）的评测体系，为社区"爬坡"到合格 AI 科研助手提供路标。

    核心 idea：专家出题 + 严格二元判分——召集一个国际专家组，每人出"会期待自己组里强博士生答对"的原创题，互评迭代专门挖 LLM 的失败模式；评分上抛弃习题式的部分给分，只认确定性、客观的对错，并扩展 LaTeX→SymPy 解析器使其理解非对易算符的规范序等价。

    方法详解¶

    整体框架¶

    CMT-Benchmark 由两条管线组成：一条是专家出题—验证管线（在定制化的 Google Sheet 上出题、与 LLM 对抗式迭代加难、再由其他专家复核），产出 50 道横跨 7 类计算/理论方法 + 模型构建的原创题；另一条是自动解析—评分管线（把作者与模型的最终 boxed LaTeX 答案都解析为 SymPy 表达式，做数值或符号等价判定，并特别支持非对易算符的规范序归约）。两条管线在 Google Sheet 集成中闭环：出题者实时看到所有模型在所有题上的表现，从而精准定位"能让全部模型翻车"的角度。

    flowchart LR
    A[专家在Google Sheet出原创题] --> B[对抗式迭代:<br/>调LLM测试并加难]
    B --> C{全部模型都答错?}
    C -->|是| D[另一专家复核正确性]
    C -->|否| B
    D --> E[纳入50题数据集]
    E --> F[LaTeX→SymPy解析]
    F --> G[数值/符号等价判定<br/>含非对易算符规范序]
    G --> H[二元判分 对/错]

    关键设计¶

    1. 专家组对抗式出题，把难度"逼"到研究前沿：传统众包在 CMT 这种小众高专业领域失效，于是作者召集国际专家组（顶校博后与教授）每人贡献原创题，要求题目无歧义、唯一可验证、可被机器解析判分，并附书面解题说明供他人复核。关键在于出题者能在 Sheet 上把题目直接喂给 Gemini 2.0/2.5、GPT-4o 等模型试做，利用模型的失败模式反复加难——一旦某题让所有可用模型全错，就交由另一位专家复核后纳入。这套"人机对抗迭代"既消除了题目歧义，又系统性地把难度推到现有模型的能力天花板之外，最终 50 道题里有 18 道无一模型能解、26 道至多一个模型能解。

    2. 非对易算符代数的自动判分：量子多体的核心是形如 \(H=\sum_{ij}t_{ij}c_i^\dagger c_j + U\sum_i n_i\) 的算符表达式，标量代入式的判分对它无效。作者扩展了数学基准里的 LaTeX→SymPy 解析器：让出题者私下声明哪些表达式含非对易算符（该声明不传给模型），评分时把这些表达式替换为非对易 SymPy 符号，再套用标准物理化简规则（如费米子反对易关系 \(\{c_i,c_j^\dagger\}=\delta_{ij}\)）把作者答案与模型答案都归约到规范序（normal ordering）这一对序敏感的标准形，最后用 SymPy 符号等价检查判定。这让基准得以覆盖"算符表达式正确性"这一 CMT 不可或缺的维度。

    3. 严格二元判分 + 多模态答案格式：受"科研结论必须绝对正确、可复现"的信念驱动，评分不给部分分，只判对/错。为保证可自动化又能多角度考查，题目设计了四种作答模态：数值、多选（多数题选项 > 5 个以防"蒙对"）、代数表达式、非对易算符表达式。模型被要求把最终答案放进 boxed LaTeX 环境且不得引入新变量；管线只评最后一个 boxed 表达式、刻意丢弃中间推理链，使基准聚焦于最终研究结论，同时为未来评估推理过程留出扩展口。

    4. 八类题型覆盖 CMT 方法全谱：数据集按内容分 8 类——Hartree–Fock（自洽平均场/序参量对称性分类）、Exact Diagonalization（有限尺度谱与守恒量识别）、DMRG（键维标度/关联长度/边界效应）、Quantum Monte Carlo（符号问题诊断）、Variational Monte Carlo（对称性投影恢复）、PEPS（iPEPS 激发与张量网络）、Statistical Mechanics（非平衡随机动力学/组合模型），以及考查模型构建与基本原理运用的 "Other"。每类都配代表性例题（如 Kitaev 交替链开边界基态简并度、J1–J2 波函数恢复 C4 旋转对称性等），从多个方法论角度系统压力测试模型。

    实验关键数据¶

    相对友好的题型 PEPS（技术性强）：GPT-5/o3 达 66.7%
    无解题 50 题中 18 题无一模型能解，26 题至多一个模型能解，集中在 QMC/VMC/DMRG

    关键发现（失败模式诊断）¶

    • 语言↔数学/几何切换失败：无法把"近半填充 Kagome 格点费米 Hubbard 模型"这类口头描述精确翻译成算符 Hamiltonian，产生违反物理定律的表达式；几何推理（如数 Fermi 面）也是弱项。
    • 不会从基本原理出发做判断：对称性等基本原理仅被当作"调出教科书例子"的关键词；如混合场 Ising 模型本无 Z2 对称性可破，部分模型仍预测对称破缺相变。
    • 依赖启发式：QMC 效率题里常把瓶颈误归为"符号问题"，需在 prompt 明确"无符号问题"后才找对真正瓶颈。
    • 看不出可化简的隐藏结构：识别不出能映射到自由费米子或潜在共形场论的结构。

    亮点与洞察¶

    • 硬科学版 FrontierMath：首个由专家组亲手出题、同时考查解析推理与计算推理、面向"科研助手就绪度"的凝聚态理论基准，定位明确填补了 GPQA 饱和、HLE 泛而不深的空白。
    • 非对易算符判分是真正的工程创新：把规范序归约 + 反对易关系塞进自动评分管线，让符号判分第一次能覆盖量子多体的核心表达式——这是同类数学/物理基准都绕开的硬骨头。
    • "对抗式出题"自带难度保证：出题流程本身就把题目逼到现有模型天花板之外，使基准短期内不易被刷爆，也顺带产出了一份宝贵的失败模式清单。
    • 结论冷峻而有价值：30% 的天花板 + 11.4% 的平均，用确定性证据反驳了"前沿模型已可当科研助手"的乐观叙事。

    局限与展望¶

    • 规模小（仅 50 题）：因专家出一道题需数小时，统计噪声相对偏大（平均带 ±2.1% 误差），细分到 8 类题型每类样本更少，单题对题型 Pass@1 影响显著。
    • 只评最终 boxed 答案、丢弃推理链：无法区分"蒙对"与"真懂"，也未评估推理过程质量；作者已把这留作未来扩展。
    • 闭卷零样本、无工具：未接入绘图/计算工具，而几何推理（如画 Fermi 面）恰恰需要工具，当前设定可能低估了 agent 化模型的真实上限。
    • 评分管线仍有缝隙：少数题（尤其 Gemini 2.5 Pro 不守格式）解析失败需人工判分；机器评分代码尚未释放，复现性待补。
    • 展望：把基准接入工具/推理评估、扩大题量、覆盖更多硬科学子领域，逐步把它变成驱动"AI 科研助手"研发的长期路标。

    相关工作与启发¶

    • 数学专家基准（FrontierMath、MathArena）：本文方法论上的直接对标，证明"顶尖专家联合出题 + 自动判分"是造研究级基准的可行范式，CMT-Benchmark 把它移植到硬科学。
    • 科学基准谱系（GPQA、HLE、SciCode、TPBench、PhySense、CMPhysBench）：前者要么饱和要么停留在学生习题层；CMPhysBench 虽聚焦凝聚态但用 SEED 给部分分、面向教科书题，本文则用二元判分 + 研究前沿题与之拉开身位。
    • LaTeX 自动解析（Roggeveen et al. 2025）：评分管线的解析基座，本文在其上新增非对易算符支持。
    • 启发：(1) 在专业小众领域，"专家对抗式出题"比众包更能造出有区分度的难基准；(2) 想测科学推理就必须解决领域特有的表达式等价判定（这里是算符代数），否则评测维度会塌缩；(3) 失败模式分析本身就是 LLM 改进的路线图——语言↔数学切换、基本原理判断、隐藏结构识别是下一步攻坚点。
