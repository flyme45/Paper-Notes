    EARTHSE：地球科学知识探索基准¶

    会议: ICLR 2026
    论文: OpenReview
    代码: https://huggingface.co/ai-earth
    领域: LLM 评估
    关键词: 地球科学基准、LLM 评估、科学探索、多任务、开放式对话

    一句话总结¶

    EARTHSE 从 10 万篇地球科学论文构建三层递进式基准（广泛QA → 专业QA → 开放对话），覆盖5大地球层114个子领域11类任务，系统评估LLM在基础知识和科学探索两个维度的能力，揭示现有LLM在领域深度和开放式思维上的显著短板。

    研究背景与动机¶

    领域现状：虽然LLM在通用科学QA上表现不错（ScienceQA、MMLU等），但这些基准要么覆盖不够深（地球科学的五大层系、114个子领域难以全面触及），要么只聚焦单一子领域（如气候、海洋），无法对地球科学这一跨学科、多尺度复杂系统进行整体评估。

    现有痛点：(1) 现有科学基准几乎都采用QA格式，只能考察事实回忆和已知知识推理，无法评估LLM进行开放式科学探索的能力——包括识别方法局限、提出改进思路、跨域类比创新；(2) 地球科学的复杂性（数据多维度、概念树深、计算密集）在通用基准里被大幅简化，LLM看起来会答题，但实际面对专业计算、术语定义、工具选择时暴露大量漏洞；(3) 评估标准单一（通常只有准确率），无法反映科学思维的多样性和深度。

    核心矛盾：地球科学的核心价值在科学探索而非知识背诵，但现有工具只评估后者。这导致一个假象——LLM 在通用基准上达到85%+ 准确率，却在真实地球科学问题上漏洞百出。

    本文目标：(1) 构建地球科学专属、足够深的基准，覆盖全领域；(2) 同时评估基础知识和高阶科学探索能力；(3) 引入开放式对话来模拟真实科学发现过程；(4) 设计新指标（SES）同时衡量答案质量和思维多样性。

    切入角度：论文观察到真实科学研究中的一个通用模式——"批判现有方法的局限 → 提出改进"，这个迭代自洽过程可以形式化为递推公式：\((M^{i+1}, L^{i+1}) = \text{LLM}(M^i, L^i)\)，其中 \(M\) 代表方法、\(L\) 代表其局限。一个真正有科学发现潜力的模型必须在这个闭环中保持自洽和递进。

    核心 idea：用三层递进式数据集（广度 → 深度 → 探索）分离评估不同能力，用开放式对话代替单轮QA来捕捉科学思维的真实样貌，用组合指标（SES = retention × diversity）同时评估答案质量和思维多样性。

    方法详解¶

    整体框架¶

    EARTHSE 的构造流水线从 10 万篇论文出发，分三条平行路线构建三个数据集。首先用论文摘要和关键词对论文按地球科学的五大层系（生物圈、岩石圈、大气圈、水圈、冰冻圈）分类；从中按出版质量、引用量逐步筛选出三个递进式子集（基础集 \(P_{\text{base}}\) 10 万篇 → 高质量集 \(P_{hj}\) 1 万篇 → 高引集 \(P_{hc}\) 1 千篇）。然后用两套不同的构造管道：QA管道生成两个阶梯式QA数据集（Earth-Iron、Earth-Silver），对话管道从高引论文中结构化抽取科学探索模式生成开放对话数据集（Earth-Gold）。两条管道都包含自动清洗（格式检验、规则剔除）和人工验证（专家多维度评分），最终交付三个既独立又协同的基准。

    关键设计¶

    1. 三层递进式数据集架构：基础广度 → 专业深度 → 探索维度

    Earth-Iron（基础层）含 4133 道题目，横跨 114 个子领域和 11 类基础科学任务（术语解释、知识QA、事实验证、逻辑分析、关系抽取、计算、工具选用、文献引用、数据集推荐、实验设计、代码生成），强调对地球科学基础概念的广泛掌握。Earth-Silver（深度层）用高影响力期刊的论文生成更难、更专业的问题，难度显著提升（多选平均只有54%准确率 vs Iron的89%）。Earth-Gold（探索层）则完全跳出单轮QA，改用开放式多轮对话，让模型在"评析现有方法的不足 → 提出改进方案 → 反思新方案的局限"的迭代过程中展现科学思维能力。三个数据集对应科学能力的三个台阶：记忆事实 → 深度理解 → 创新思考。

    2. 论文自动结构化抽取 + 人工多维度验证的质控体系

    对 Earth-Iron/Silver 的QA生成，先用小LLM分析论文摘要选择最合适的11类任务之一（如含大量数值结果的论文优先生成计算题），再用 GPT-4 在给定论文内容和任务提示下生成QA对。关键是生成时强制要求模型提供完整的思维链（CoT）推导过程，这个CoT既是答案的组成部分，也是后续数据清洗的"证据"——如果CoT本身有矛盾或不支持最终答案，就能自动检出LLM幻觉。清洗分两阶段：规则基清洗（格式检验、选项缺失、答案不规范）→ 语义清洗（多个正确选项、答案与问题不相关）。此外还进行难度筛选：用主流LLM测试，准确率>80% 的题目删除（太简单），60%-80% 的题目由专家判断是否值得保留。对 Earth-Gold 的对话生成，先从论文的相关工作、动机、方法、讨论等章节结构化提取四元组 (\(M_0, L_0, M_1, L_1\))——现有方法、其局限、新方法、新方法的局限。然后用 GPT-4 生成两轮对话：第一轮要求AI总结现有方法并批判其局限；第二轮要求AI提出改进方法并客观评估新方案的约束。最后由领域专家用三维标准评分：(a) 信息密度（是否含具体分析方法/数据集/事件），(b) 方法质量（提出的改进是否系统可实现），(c) 逻辑一致性。

    3. Scientific Exploration Score (SES) 指标：同时衡量答案质量和思维多样性

    对开放式问题无法用单一"正确答案"判分，EARTHSE 创新性地定义了 SES 来评估科学探索能力。核心思想是：模型生成 \(M\) 个多样的回答（温度0.6），然后计算两个维度：

    • Retention rate \(r\)：用GPT-4对 \(M\) 个生成答案和参考答案按"反思深度和创新性"排名，取参考答案的排名位置 \(i\)，则 \(r = \frac{i-1}{M}\)。如果所有生成答案都不如参考答案，则 \(r=0\)；如果参考答案排第一，则 \(r = 1\)。这衡量模型答案的"保质率"。

    • Diversity \(d\)：用 sentence-transformer 生成每个回答的嵌入向量 \(v_i\)，计算平均向量 \(\bar{v} = \frac{1}{M}\sum_i v_i\)，然后求平均余弦相似度 \(\bar{s} = \frac{1}{M}\sum_i \cos(v_i, \bar{v})\)。相似度越低说明回答越多样，所以定义 \(d = \frac{1}{\bar{s}}\)。这衡量模型在同一问题上的"思维发散度"。

    • SES组合指标：\(\text{SES} = r \times d\)（将 \(\bar{s}\) 归一化到 \([0.9, 1]\) 进行调整，即 \(\text{SES} = \frac{r}{10 \times (\bar{s} - 0.9)}\)）。SES更高表示答案既质量好（高retention）又思维多样（高diversity），反映出"既把问题想深了，又能从多个角度看问题"的科学家素质。

    4. 多格式QA设计 + CoT 指导策略

    Earth-Iron/Silver 的QA包含四种格式：多选题（MC）、填空题（FIB）、真假题（TF）、自由答题（FR）。MC/TF/FIB 用准确率（Acc）判分；FR 用两个指标：(a) Win Rate（WR）——用GPT-4 按"相关性、科学严谨性、具体性"三维对比模型答案和参考答案，胜率多少为WR；(b) Semantic Similarity（SS）——用 sentence-transformer 计算两答案的余弦相似度。此外论文发现FIB准确率特别低（平均11%），通过实验发现：即使不改模型能力，在推理时给模型提供初步的CoT步骤提示，准确率大幅提升（0步→1步→3步，准确率从12.8% → 21.6% → 45.6%），这为"推理时缩放"提供了新思路。

    关键发现¶

    1. 多选题看似简单，但填空题暴露漏洞：多选平均89%，但填空题仅14.5%，说明LLM对地球科学概念的理解多停留在"能识别"而非"能复述/计算"阶段。

    2. Earth-Silver的难度峭壁：MC从89%骤降到54%（仅比随机猜测好29%），平均掉幅35个百分点。这反映出：即使是顶级模型也难以在专业级地球科学问题上稳定表现，地球科学的深度远超模型训练数据里的"地球科学"覆盖度。

    3. 计算能力是通病：几乎所有模型在涉及多步公式、单位转换、数值推导的题目上都大幅失利。案例分析显示常见错误是"选对公式但代错变量""忘记单位换算""中途计算笔误"——这不是理解问题而是执行问题。

    4. 开放式探索能力极度缺乏：Earth-Gold 上超过75% 的模型生成回答都逊于参考答案（retention<50%）。更严重的是多样性极低——同一问题，模型多次生成的答案高度相似（平均 \(\bar{s}\) 接近1），这恰恰违背科学探索需要的"多角度思考"。人类科学家面对"如何改进气候模型"这类问题，会想到"改进参数化""加高分辨率""融合观测数据""用AI替代物理模型"等多条线路；但LLM倾向于生成一个"最安全"的答案，然后重复。

    5. CoT指导的威力：在推理时提供初步CoT步骤，FIB准确率从12.8% 翻3倍到45.6%。这提示未来改进方向：与其训练更大的模型，不如在推理时设计更好的脚手架。

    亮点与洞察¶

    • 三层递进式基准的设计妙处：用广度（Iron）→ 深度（Silver）→ 探索（Gold）三个维度分离不同能力，避免用单一数字"LLM在地球科学上的表现"来掩盖本质差异。这个框架本身是一个可迁移的"基准设计模板"，对其他科学领域建立基准很有启发。

    • 开放式对话代替单轮QA的转变：传统基准只考察"给问题输出一个答案的能力"，但真实科学发现是"不断质疑、迭代改进"的过程。Earth-Gold 用递推公式 \((M^{i+1}, L^{i+1}) = \text{LLM}(M^i, L^i)\) 形式化了这个闭环，是评估科学思维的新范式。

    • SES指标的组合设计：用 retention（质量）× diversity（多样性）的乘法组合，而非简单加权，会严厉惩罚那些"虽然一个答案不错但完全不会变通"的模型。这符合科学家的特质要求。

    • CoT作为质控工具的双重用途：论文用CoT不仅作为答案组成部分，还作为自动检错的"证据链"。这个思想可推广到任何基准生成任务。

    • 五大地球层的平衡覆盖：数据集构造时严格保持五大地球层（生物、岩石、大气、水、冰冻）的样本平衡（各占20%左右），避免某个子领域数据过载。这种平衡设计对多领域基准的公平性很重要。

    局限与展望¶

    • 作者承认的局限：论文明确指出目前11个任务没有集成为更复杂的"任务链"，真正的自动科学发现应该是多任务的有机结合（如"设计实验 → 分析数据 → 解释现象 → 提出改进"），但这超出本基准的范围。

    • 自己发现的局限：

      • Earth-Gold 目前只有两轮对话，真实科学研究通常需要更多轮迭代；只有1000篇高引论文，对覆盖面的充分性有疑问。
      • SES 指标的计算依赖 GPT-4 的排名（主观性风险）和 sentence-transformer 的相似度（可能无法捕捉语义上微妙的差异）。
      • FIB 题目的极低准确率（11%平均）可能反映题目本身的设计难度过高（是否存在"无差别难"而非"科学上的难"？），而非模型能力真的那么差。
      • 论文没有区分"地球科学知识的缺失"vs"通用推理能力的缺失"——某些失分是因为LLM没见过这个地球科学概念，某些是计算能力本身弱。

    • 具体改进思路：

      • Earth-Gold 可扩展为 5-10 轮对话，模拟完整的论文撰写过程。
      • 引入"自洽性"指标：检查 \(M^{i+1}\) 是否真的解决了 \(L^i\) 指出的问题，还是只是生成了另一个听起来合理的方案。
      • 为FIB和计算题建立专项的CoT-引导推理协议，测试"给脚手架vs不给脚手架"的天花板差异。
      • 纳入多模态问题（图表、数据可视化），因为地球科学中空间信息和时间序列极其重要。

    相关工作与启发¶

    • vs ScienceQA/MMLU-Pro/SciBench：这些通用科学基准追求广度，但地球科学在其中严重不足。EARTHSE 的做法是"舍广度求深度"——放弃覆盖所有科学（生物、物理、化学、社会科学），而是对地球科学进行 114 个子领域 × 11 类任务的密集采样。启发是：有时候细致的细分比盲目的广覆盖更有评估价值。

    • vs OceanBench/ClimaQA/GeoBench：这些单领域基准已经证明了专属基准的必要性，但都停留在单个QA。EARTHSE 的贡献是引入"开放对话层"来评估探索能力，这改变了基准的维度定义。

    • vs 自动科学发现系统（如AlphaFold、AlphaProtein）：这些系统用LLM+专有工具进行端到端发现。EARTHSE不是工具系统，而是一个"测试LLM的科学思维能力"的基准，两者互补——基准用于诊断现状，工具系统用于探索未来。
