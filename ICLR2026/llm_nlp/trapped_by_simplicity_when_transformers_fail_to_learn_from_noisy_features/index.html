    Trapped by simplicity: When Transformers fail to learn from noisy features¶

    会议: ICLR 2026
    arXiv: 2602.08695
    代码: https://github.com/peterse/noise-robust-boolean-learning/
    领域: LLM NLP / Transformer理论分析
    关键词: 噪声鲁棒学习, 简单性偏好, 布尔函数, Transformer, 敏感度

    一句话总结¶

    研究表明 Transformer 在从含特征噪声的数据中学习布尔函数时会失败——其简单性偏好（倾向学习低敏感度函数）导致模型被困在比目标函数更简单的最优噪声预测器上，无法恢复真实的无噪声目标函数。

    研究背景与动机¶

    领域现状：LLM 的训练数据中普遍包含噪声（拼写错误、语法错误、语义不一致等），但这些模型常被应用于对噪声高度敏感的任务（如算术推理），其中每个 token 的预测都依赖于前面无噪声的输入。已有研究表明 Transformer 在无噪声训练后对测试时的噪声具有鲁棒性，但对"训练数据本身含特征噪声"时的学习能力研究不足。

    现有痛点：已知 Transformer 具有简单性偏好（simplicity bias），倾向学习低敏感度（sensitivity）的布尔函数。之前的工作主要关注标签噪声的影响，而特征噪声（输入比特翻转）的影响定性上完全不同——它使最优预测器 \(f_N^*\) 比目标函数 \(f\) 更简单。

    核心矛盾：当训练数据存在特征噪声时，贝叶斯最优预测器 \(f_N^*\) 通常比目标函数 \(f\) 具有更低的敏感度。Transformer 的简单性偏好恰好使其偏向学习 \(f_N^*\) 而非 \(f\)，导致在无噪声数据上泛化失败。

    本文目标 Transformer 能否从含特征噪声的数据中学习到正确的无噪声目标函数（噪声鲁棒学习）？在什么条件下会成功/失败？如何解释和缓解失败？

    切入角度：通过布尔函数的理论框架分析——利用敏感度作为复杂度度量，从信息论和噪声信道编码的视角建立噪声鲁棒学习的理论框架，并设计"陷阱函数"控制实验来隔离简单性偏好的影响。

    核心 idea：Transformer 的简单性偏好使其在特征噪声下被"困"在更简单的最优噪声预测器上，对随机布尔函数的噪声鲁棒学习系统性失败。

    方法详解¶

    整体框架¶

    这篇论文要回答一个具体问题：当训练数据的输入被噪声污染、但标签干净时，Transformer 还能不能学到真正的目标函数？为此作者把问题抽象成布尔函数学习，并配上一套理论 + 控制实验。设定是这样的：输入是长度为 \(n\) 的二进制串 \(X\)，要学的目标是布尔函数 \(f(X)\)；训练时模型看到的输入 \(Z = X \oplus E\) 经过了独立的比特翻转噪声（每位翻转概率 \(p\)），而标签 \(Y = f(X)\) 本身无噪声。关键在于训练和测试的分布错位——模型在噪声数据 \((Z, Y)\) 上训练，却要在无噪声数据 \((X, Y)\) 上泛化。整套分析就是围绕"模型在这个错位下会收敛到什么"展开：先用噪声信道编码的视角导出理论上的最优预测器 \(f_N^*\)，再区分两类函数——对 parity / 奇数 maj 这类"自预测函数" \(f\) 本身就是最优解、学习成功，对一般随机布尔函数 \(f_N^*\) 却系统性地更简单，于是 Transformer 的简单性偏好会把它困在 \(f_N^*\) 上、学不到 \(f\)；最后用陷阱函数的控制实验坐实"是简单性偏好本身、而非验证误差差距"导致了失败。

    这是一篇理论/分析论文，没有可画的网络结构，但它的论证本身是一条有分叉的逻辑链，因此用一张 flowchart 把"从噪声数据到成功/失败两条路径、再到缓解手段"的推理流程画出来，与下面四个关键设计一一对应（自上而下：噪声信道编码视角 → 自预测函数 / 随机布尔函数敏感度分析 → 陷阱函数控制实验）：

    关键设计¶

    1. 噪声信道编码视角：把"从噪声学习"翻译成通信问题

    要分析特征噪声的影响，先得有个能精确刻画它的框架。作者把下一 token 预测建模成一次通信：发送方 Alice 把信息 \(Y = f(X)\) 编码进序列 \(X\)，接收方 Bob 收到的却是噪声版本 \(Z\)，于是"学习"就等价于"在噪声信道下解码"。在这个视角下，贝叶斯最优预测器有闭式形式 \(f_N^*(x) := \text{sign}(T_{1-2p} f(x))\)，其中 \(T_\rho\) 是噪声算子；最优错误率则被 Fano 不等式夹在一对信息论上下界之间：

    \[\Phi^{-1}(H(Y|Z)) \leq \text{err}_f(f_N^*) \leq \phi^{-1}(H(Y|Z))\]

    这套噪声信道编码的语言和以往基于压缩（源编码）的分析不同——源编码关心如何把干净信息压短，而这里的核心矛盾是噪声本身怎么改变最优解，信道编码的视角正好能精确描述特征噪声对学习的影响。

    2. 自预测函数：为什么 parity 和多数函数看起来"没问题"

    如果只看 parity 和奇数位多数函数，会得出过于乐观的结论，这一点需要先澄清。命题 1 证明：对 \(\text{maj}_n\)（\(n\) 为奇数）和 \(\text{parity}\)，目标函数本身就是噪声数据上的最优预测器，即 \(f = f_N^*\)。这意味着在这些函数上，普通的损失最小化就足以学到目标函数，根本不存在"被更简单的解困住"的问题。实验也印证了这点：Transformer 在 \(\text{maj}(20,5)\)、\(\text{maj}(40,5)\) 和 \(\text{parity}(20,4)\) 上都能成功做噪声鲁棒学习，中位数 Transformer 还优于最佳 LSTM。换句话说，这些被反复研究的函数恰恰是特例——它们的成功不能推广到一般情况。

    3. 随机布尔函数的敏感度分析：最优噪声预测器系统性地更简单（核心理论贡献）

    把目光从特例移到一般的随机布尔函数，结论就翻转了。命题 2 证明：对均匀随机采样的布尔函数 \(f\)，当 \(n\) 足够大时，最优噪声预测器的平均敏感度为

    \[\mathbb{E}_f[I[f_N^*]] \approx \frac{n}{\pi} \arccos\left(\frac{2p(1-p)}{p^2+(1-p)^2}\right)\]

    并且 \(\mathbb{E}_f[I[f]] > \mathbb{E}_f[I[f_N^*]]\)——也就是说，最优噪声预测器平均比目标函数更简单（敏感度更低）。实验在 3200 个随机 \(k\)-junta 上验证了这一点：所有样本都满足 \(I[f] \geq I[f_N^*]\)。这正是全篇的关键发现：既然 \(f_N^*\) 比 \(f\) 简单，而 Transformer 又天生偏好低敏感度的解，它就会顺势学到 \(f_N^*\) 而不是真正的 \(f\)。

    4. 陷阱函数控制实验：把简单性偏好从其他混淆因素里隔离出来

    光证明"更简单"还不够，得排除"模型只是因为验证误差更低才选 \(f_N^*\)"这个混淆。作者为此专门构造了一类陷阱函数，使验证误差几乎相等（\(\text{err}_f(f_N^*) \approx \text{err}_f(f)\)）但敏感度差距很大（\(I[f_N^*] \ll I[f]\)）。在这种设置下，模型原则上完全可以靠损失最小化学到 \(f\)，可 Transformer 仍然被简单性偏好"困住"，收敛到更简单的 \(f_N^*\)；LSTM 也失败，但原因不同，是过拟合了训练数据。进一步地，只要在损失里加一个敏感度惩罚项 \(-\lambda I[\hat{f}]\)（惩罚低敏感度解），Transformer 就能逃出陷阱、学到 \(f\)。这条因果链直接坐实了——是简单性偏好本身、而非验证误差差距导致了噪声鲁棒学习的失败。

    损失函数 / 训练策略¶

    • 标准训练：最小化噪声数据上的交叉熵损失
    • 改进训练：添加复杂度偏好项 \(-\lambda I[\hat{f}]\) 惩罚低敏感度解
    • \(\lambda\) 的选择非常关键——存在一个窄窗口使 Transformer 能逃脱陷阱

    关键发现¶

    • Transformer 在随机 k-junta 上系统性失败：3200 个随机函数中，只有 \(I[f] \approx I[f_N^*]\) 的少数函数能成功学习
    • 失败的核心原因是简单性偏好：Transformer 达到近最优验证误差（在噪声数据上表现好）但无噪声测试表现差——验证损失不能指导选择正确模型
    • LSTM 失败原因完全不同：不是简单性偏好，而是过拟合训练数据
    • 敏感度差异越大，学习越困难：\(I[f] - I[f_N^*]\) 与无噪声泛化误差呈正相关

    亮点与洞察¶

    • 简单性偏好的双面性：之前的研究将 Transformer 的简单性偏好视为优势（泛化好），本文揭示在特征噪声下它成为系统性失败的根源。这个视角转换非常有启发性
    • "陷阱函数"实验设计：通过精心构造 \(\text{err}(f_N^*) \approx \text{err}(f)\) 但 \(I[f_N^*] \ll I[f]\) 的函数，巧妙地隔离了简单性偏好的影响，排除了"验证误差差距"这一混淆因素
    • 信息论视角：将噪声鲁棒学习与噪声信道编码联系起来（而非通常的压缩/源编码），提供了全新的分析工具
    • 对 LLM 训练的启示：如果训练语料中存在足够多的噪声/随机性，LLM 可能无法学到精确的离散推理规则（如算术），因为简单性偏好会使其学到"近似但不精确"的解。这可迁移到解释 LLM 在数学推理中的不可靠性

    局限与展望¶

    • 噪声模型过于简化：仅考虑独立同分布比特翻转，真实语言噪声（语法错误、语义不一致）的结构化特征未被捕捉
    • 函数类型受限：实验限于随机 k-junta，可能不代表真实学习问题的复杂度
    • 高噪声率要求：许多观察到的效应需要相对高的噪声率，在自然数据集中可能不常见
    • 敏感度惩罚不实用：逃脱陷阱需要精确调节 \(\lambda\)，在实际应用中缺乏可操作性
    • 可改进方向：研究更复杂的噪声模型（如自然语言中的语义噪声）对结论的影响；探索替代简单性偏好缓解方法（如课程学习、噪声感知训练）
